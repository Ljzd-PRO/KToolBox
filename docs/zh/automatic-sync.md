# 自动同步

“**自动同步**”页面按计划复用现有作者同步流程。每次运行都会创建普通同步任务，因此仍可在“**任务**”页面查看进度、失败原因、暂停、停止和日志。

![自动同步计划与最近更新](../assets/webui/37-auto-sync-desktop-light.png)

## 创建计划

1. 先把作者加入当前项目的作者清单。
2. 打开“**自动同步**”，选择“**新建计划**”。
3. 勾选一位或多位作者。
4. 选择标准五段 Cron 计划，或不少于 15 分钟的固定间隔。
5. 选择 IANA 时区，并核对未来三次执行时间。
6. 选择首次检查日期和同步选项，然后保存。

![Cron 计划与未来执行预览](../assets/webui/38-auto-sync-schedule-preview-light.png)

Cron 图形设置支持每小时、每天、每周和每月等常见计划；高级设置可输入标准五段表达式。固定间隔使用稳定锚点，“**立即执行**”不会改变下一次自动运行时间。

## 检查点与最近更新

每次运行开始前会固定本次截止时间。KToolBox 优先使用 Pawchive 具有 UTC 语义的 `added` 时间，从上次成功检查点向前重叠 24 小时，并按平台、作者 ID 和作品 ID 去重，既避免漏检，也不会重复统计同一作品。

- 同步成功的作者推进自己的检查点。
- 失败作者保留旧检查点，其他成功作者仍可正常推进。
- 首次选择“**不限起始日期**”时只建立基线，不把全部历史作品计为新增。
- “**立即执行**”与定时运行使用并推进同一检查点。
- 最近更新只显示作者和新增作品数量，不加载作品标题或媒体。
- **新增作品**卡片同时控制统计总数和下方列表的周期：**当天**从本地零点开始计算，**近 1 天**、7 天、14 天和 30 天均为滚动时间窗口。

## 暂停、冲突与停机

暂停计划只阻止未来自动触发，不会停止正在执行的任务；暂停后仍可手动立即执行。同一计划已有活动任务时，定时触发会记录为跳过，“立即执行”会提示并允许打开现有任务。

KToolBox 停止期间错过的计划不会补跑；再次启动后会直接计算第一个未来执行时间。
