# WebUI プロジェクトワークフロー

WebUI をインストールしてプロジェクトへ接続した後、このページでプロジェクトのデータと設定を管理します。タスク実行とデプロイ情報は専用ガイドに分かれています。

## プロジェクトのワークフロー

初回はブラウザ言語に従い、簡体字中国語、繁体字中国語、英語、日本語、韓国語、フランス語、ロシア語の選択を保持します。言語を切り替えると、React Aria の日付、数値形式、自然順ソート、設定メタデータ、入力検証、既知のサーバーエラーも同時に更新されます。ライトまたはダークを選ぶまでは OS のテーマに従います。青、エメラルド、紫、ローズ、アンバーのアクセントを選べますが、有効なフォームスイッチは全パレットで青のままです。デスクトップはコンパクトなサイドバー、狭い画面は Drawer を使います。

![7 言語セレクター](../../assets/webui/23-language-menu-seven-locales.png)

![ライト設定エディター](../../assets/webui/09-configuration-light.png)

編集領域は控えめな第 2 サーフェスと明確なフィールド背景を使います。アイコンで確認しやすくし、スイッチとチェックボックスは中央の操作ボタンのようにせずラベルと左揃えにします。スイッチはオフがグレー、オンが青で、チェックボックスは選択または不確定時だけ印を表示します。編集モーダルと固定アクションバーは連続したサーフェスを共有します。

主な領域：

- **概要：**プロジェクトパス、キュー状態、アクティブ転送合計、最近のタスク。
- **タスク：**同期または単一作品ダウンロードの作成、編集、一時停止、再開、停止、再実行、削除、確認。読みやすい対象リンクだけが詳細を開き、操作ボタンが誤って画面遷移を起こしません。複数選択で対応する一括操作も実行できます。
- **自動同期：**複数の定期クリエイター同期プランを作成し、最近の更新数と実行履歴を確認し、プランの一時停止や即時実行を行います。
- **クリエイター：**Pawchive の検索と一覧項目の追加、メモ編集、有効化、無効化、削除。一括での有効化、無効化、削除にも対応します。
- **投稿：**作品の検索、改訂の確認、ダウンロードタスクの作成。画像プレビューは NSFW モードを明示的に有効にした場合だけ表示し、本文は既定で折りたたみます。
- **除外ルール：**`field-match` の順序とスコープ、ネストした `any`/`all`、包含、等価、正規表現、存在条件の構成。
- **グローバル設定：**型付きフォームまたは高度なテキスト表示で `.env`、`prod.env`、`ktoolbox.toml` を編集。
- **システム：**プロジェクトとアプリのバージョン確認、環境例のダウンロード。
- **情報：**KToolBox のバージョン、ライセンス、実行環境、作者、ドキュメント、リポジトリ、問題報告先を表示し、作者メールは公開しません。

![狭い画面のタスクエディター](../../assets/webui/19-task-form-mobile-light-zh.png)

![Pawchive クリエイター一覧](../../assets/webui/41-creators-showcase-desktop-light.png)

タスク作成はオーバーフロー操作のない 2 つの固定タブを使います。同期日付は公式 HeroUI の 1 つの `year/month/day - year/month/day` 範囲フィールドのままで、「開始日なし」と「終了日なし」はそれぞれの境界を個別に消去します。投稿オフセットは 50 ずつ変更されます。タイトルフィルターは、カンマまたは Enter で作成する削除可能な HeroUI Chip を使います。単一作品のダウンロードと一覧へのクリエイター追加は独立した HeroUI フィールドを使い、`/platform/user/creator/post/post` のようなコード風の Pawchive パス断片で区切ります。区切りは入力フィールドとして模造しません。

デスクトップ行とモバイル項目はどちらもクリエイター ID を先頭に表示します。任意の一覧メモは別に表示され、ID を置き換えません。既存のクリエイターを編集するとき、プラットフォームとクリエイター ID は一覧項目を識別するため、表示されたまま読み取り専用になります。

## オプションのセンシティブメディアプレビュー

NSFW モードは新しいブラウザーでは必ずオフです。オフの間、クリエイターと作品のページはテキストのみで、画像リクエストも空のメディア領域も作りません。有効化のたびに確認が必要です。有効な状態は、利用者がオフにするまで現在のブラウザーに保存され、タブ間で同期します。

ブラウザーは認証済みの同一オリジン WebUI プロキシだけからメディアを取得し、Pawchive のファイルホストへ直接接続しません。プロキシはビットマップを完全にデコードして検証し、リダイレクト、SVG、画像以外、破損ファイル、32 MiB または 50 MP を超えるリソースを拒否して、上限付きサムネイルを生成します。アバター、バナー、作品カバー、画像添付、対応する本文画像を表示できます。ギャラリーは 12 件ずつ読み込み、ビューアーは矢印キーと Escape に対応します。動画、アーカイブ、その他の添付はテキストのままです。

## 自動同期

**自動同期**ページでは、複数のプラン、複数クリエイター、5 フィールド Cron、および 15 分以上の固定アンカー付き間隔を設定できます。各プランには IANA タイムゾーン、初回境界、出力オプション、次の 3 回の実行予定が表示されます。即時実行も同じタスクキューを使用し、成功したクリエイターのチェックポイントを進めますが、間隔スケジュールの軸は変更しません。

自動チェックは Pawchive の UTC 相当の `added` 時刻を優先し、前回成功したチェックポイントから 24 時間重ねて確認します。プロジェクト全体の重複排除により、複数プランで同じ作品を重複集計しません。初回の無制限実行は基準を作るだけで、全履歴を新規として扱いません。停止中に逃した実行はスキップされ、同じプランの実行中タスクがある場合も重複起動しません。詳しくは[自動同期ガイド](../automatic-sync.md)を参照してください。

## プロジェクトの命名

命名設定と既定出力はプロジェクトの `ktoolbox.toml` に保存され、CLI、WebUI、MCP、作品ダウンロード、自動同期で共有されます。「命名形式」ページは構造とテンプレートを個別に保存します。再利用可能な旧場所変換では、複数の保存済み形式または貼り付けた旧 `.env`/TOML を変換元にでき、現在のプロジェクト形式を読み取り専用の変換先として使い、貼り付けた原文は保存しません。明示選択した場所だけを Pawchive に接続せずスキャンし、一時停止、再開、ロールバックに対応します。旧場所が今後の保存先になることはありません。継承、旧設定移行ウィザード、復旧は[命名形式ガイド](../naming.md)を参照してください。

## 設定の編集

フォームのラベルと説明は Python 識別子ではなく、明示的にローカライズされたテキストです。英語設定クラスの `:ivar field:` docstring は引き続きフィールド意味の基準であり、完全性を検査した言語カタログが 7 言語すべてのラベルと説明を提供します。型、既定値、範囲、シークレット情報は Pydantic が提供します。

ログレベルなどの固定候補は、アイコン付き HeroUI Select を使います。推奨値がありながら任意入力も有効な項目は ComboBox です。`attachments`、`content.txt`、`external_links.txt` など作品内部の名前は通常のテキスト欄であり、実際のファイルシステム位置だけにパス選択を表示します。

`.env` と `prod.env` タブは最終有効値と取得元 Chip を表示します。プロセス環境で上書きされた値は読み取り専用です。シークレットは既定でマスクされます。高度なテキスト編集はシークレットを公開し得るため追加警告を表示します。

保存前にサーバーが提案ファイルを解析・検証し、意味的差分を返します。ETag で古い編集を拒否し、ファイルをアトミックに置換します。TOML エディターは既存の TomlKit/Pydantic ストアを使うため、構造化された一覧とルールを変更してもコメントが残ります。
