# 自動同期

**自動同期**ページは既存のクリエイター同期をスケジュール実行します。各実行は通常のタスクとして作成され、進捗、失敗理由、一時停止、停止、ログを**タスク**ページで確認できます。

![自動同期プランと最近の更新](../assets/webui/37-auto-sync-desktop-light.png)

## プランを作成する

1. クリエイターをプロジェクト一覧に追加します。
2. **自動同期**で**プランを作成**を選びます。
3. 1人以上のクリエイターを選択します。
4. 5フィールドCron、または15分以上の固定間隔を選びます。
5. IANAタイムゾーンと次の3回の実行時刻を確認します。
6. 初回確認日と同期設定を選び、保存します。

![Cronと次回実行プレビュー](../assets/webui/38-auto-sync-schedule-preview-light.png)

画面設定は毎時、毎日、毎週、毎月に対応します。詳細設定では標準の5フィールド式を入力できます。**今すぐ実行**しても固定間隔の次回時刻は移動しません。

## チェックポイントと最近の更新

実行開始時に終了時刻を固定し、Pawchive の UTC 相当の `added` 時刻を優先して前回成功位置から24時間重ねて確認します。プラットフォーム、クリエイターID、作品IDで重複を除きます。

- 成功したクリエイターだけチェックポイントを進めます。
- 失敗したクリエイターは以前の位置を保持します。
- **開始日を制限しない**初回実行は基準だけを作り、全履歴を新規として数えません。
- 手動実行も同じチェックポイントを使います。
- 最近の更新は名前と件数だけを表示し、タイトルやメディアを読み込みません。
- **新規作品**カードで合計と下の一覧の集計期間を選べます。**今日**はローカルの午前0時から、過去24時間、7日、14日、30日は移動時間枠で集計します。

## 一時停止、競合、停止期間

一時停止は次の自動実行だけを止め、現在のタスクは停止しません。停止中でも手動実行できます。アプリ停止中に逃した実行は再生されず、起動後は次の未来時刻から再開します。
