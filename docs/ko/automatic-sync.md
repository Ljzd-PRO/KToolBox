# 자동 동기화

**자동 동기화** 페이지는 기존 크리에이터 동기화 흐름을 예약 실행합니다. 각 실행은 일반 작업으로 생성되므로 **작업** 페이지에서 진행률, 실패 원인, 일시 중지, 중지 및 로그를 계속 확인할 수 있습니다.

![자동 동기화 계획과 최근 업데이트](../assets/webui/37-auto-sync-desktop-light.png)

## 계획 만들기

1. 크리에이터를 프로젝트 목록에 추가합니다.
2. **자동 동기화**에서 **계획 만들기**를 선택합니다.
3. 한 명 이상의 크리에이터를 선택합니다.
4. 5필드 Cron 또는 15분 이상의 고정 간격을 선택합니다.
5. IANA 시간대와 다음 3회 실행 시간을 확인합니다.
6. 첫 확인 날짜와 동기화 설정을 정한 뒤 저장합니다.

![Cron 및 다음 실행 미리보기](../assets/webui/38-auto-sync-schedule-preview-light.png)

화면 설정은 매시간, 매일, 매주, 매월을 지원합니다. 고급 설정에서는 표준 5필드 식을 입력할 수 있습니다. **지금 실행**은 고정 간격의 다음 자동 실행 시간을 바꾸지 않습니다.

## 체크포인트와 최근 업데이트

실행이 시작될 때 종료 시각을 고정하고 Pawchive의 UTC 의미를 가진 `added` 시간을 우선 사용해 이전 성공 체크포인트에서 24시간 겹쳐 확인합니다. 플랫폼, 크리에이터 ID, 작품 ID로 중복을 제거합니다.

- 성공한 크리에이터만 체크포인트를 진행합니다.
- 실패한 크리에이터는 이전 체크포인트를 유지합니다.
- 첫 실행에서 **시작일 제한 없음**을 선택하면 기준만 만들고 전체 기록을 새 작품으로 세지 않습니다.
- 수동 실행도 같은 체크포인트를 사용합니다.
- 최근 업데이트는 이름과 수량만 표시하며 제목이나 미디어를 불러오지 않습니다.
- **새 작품** 카드에서 합계와 아래 목록의 집계 기간을 함께 선택합니다. **오늘**은 현지 자정부터 계산하고, 최근 24시간, 7일, 14일, 30일은 이동 시간 범위입니다.

## 일시 중지, 충돌 및 중단 시간

계획 일시 중지는 향후 자동 트리거만 막고 현재 작업을 중지하지 않습니다. 중지된 계획도 수동 실행할 수 있습니다. KToolBox가 꺼진 동안 놓친 실행은 다시 실행하지 않고 다음 미래 시각부터 계속합니다.
