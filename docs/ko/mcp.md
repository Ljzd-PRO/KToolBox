# MCP

KToolBox는 WebUI와 같은 프로세스와 포트에서 Streamable HTTP MCP 서버를 시작합니다. 프로젝트, 작업, 크리에이터, 제외 규칙, Pawchive 검색, 이름 형식, 자동 동기화 및 안전한 설정 기능 중 선별된 도구를 제공합니다. 브라우저 세션과 MCP 클라이언트는 서로 다른 자격 증명을 사용합니다.

| 서비스 | 기본 주소 |
| --- | --- |
| WebUI | `http://127.0.0.1:8789/` |
| MCP | `http://127.0.0.1:8789/mcp` |
| WebUI REST OpenAPI | `http://127.0.0.1:8789/api/v1/openapi.yaml` |

OpenAPI 다운로드에는 인증된 WebUI 세션이 필요합니다. 저장소의 공식 계약은 `webui/openapi.yaml`입니다.

## 액세스 토큰 만들기

1. WebUI를 시작하고 로그인합니다.
2. 사이드바의 **MCP**를 엽니다.
3. **새 액세스 토큰**을 선택합니다.
4. 알아보기 쉬운 이름을 입력하고 현재 WebUI 암호를 다시 확인합니다.
5. 읽기 전용 또는 관리 권한과 7, 30, 90, 365일 또는 만료 없음 중 하나를 선택합니다.
6. 표시된 `ktmcp_...` 값을 즉시 저장합니다. 원문은 한 번만 표시됩니다.

KToolBox는 토큰 해시만 저장합니다. MCP 페이지에서 생성, 만료 및 마지막 사용 시간을 확인하고 즉시 취소할 수 있습니다. 만료 없는 토큰은 취소할 때까지 유효하므로 수명 주기를 적극적으로 관리할 때만 사용하세요.

## Codex 연결

토큰을 저장소 밖의 환경 변수에 저장합니다.

```shell
export KTOOLBOX_MCP_TOKEN="ktmcp_..."
```

Codex 설정에 서버를 추가합니다.

```toml
[mcp_servers.ktoolbox]
url = "http://127.0.0.1:8789/mcp"
bearer_token_env_var = "KTOOLBOX_MCP_TOKEN"
```

MCP 페이지에서는 일반 HTTP, Claude, Cursor, VS Code 및 Codex용 설정도 생성합니다. 템플릿은 토큰을 직접 넣지 않고 환경 변수나 보호된 입력을 사용합니다.

## 권한과 제한

- 읽기 전용 토큰은 프로젝트 요약, 작업, 크리에이터, 제외 규칙, 자동 동기화 상태, 이름 기록, 비밀이 제거된 설정 및 제한된 프로젝트 파일을 조회할 수 있습니다.
- 관리 토큰은 도구 목록에 명시된 작업, 크리에이터, 제외 규칙, 자동 동기화 및 안전한 구조화 설정도 변경할 수 있습니다.
- 로그인, 로그아웃, 브라우저 세션, dotenv/TOML 원문 편집, 비밀 값, 임의 호스트 파일 시스템, 출력 삭제, 무제한 로그와 본문은 노출하지 않습니다.
- 검색과 Pawchive 조회는 설정된 Pawchive 서비스에 연결할 수 있는 오픈 월드 작업입니다.
- 도구 목록, 로그, 이벤트, 작품 본문 및 파일에는 상한이나 페이지 구분이 적용됩니다.

실행 중인 버전에서 실제 사용할 수 있는 도구는 **MCP** 페이지의 목록을 기준으로 합니다.

## 보안

Bearer 토큰은 프로젝트에 직접 접근합니다. Git, 셸 기록, 스크린샷, 로그 또는 채팅 메시지에 저장하지 마세요. 클라이언트마다 별도 토큰을 사용하고 사용하지 않는 자격 증명을 취소하세요.

내장 서버는 HTTP를 사용합니다. 같은 컴퓨터의 클라이언트는 WebUI를 `127.0.0.1`에 바인딩하세요. 원격 접근은 신뢰할 수 있는 리버스 프록시에서 HTTPS를 종료하고 네트워크 접근을 제한해야 합니다.

## API 구분

- Pawchive OpenAPI는 업스트림 공개 서비스를 설명합니다.
- [Python API](api.md)는 형식화된 `PawchiveClient`를 제공합니다.
- `webui/openapi.yaml`은 인증된 KToolBox WebUI REST API를 설명합니다.
- `/mcp`는 WebUI 계약에서 선별한 MCP 도구를 제공합니다.

WebUI REST 계약과 MCP는 Pawchive API를 대체하지 않습니다.
