# Сведения о проекте

## Состояние выпуска

KToolBox v1 — новая линия выпуска на основе Pawchive. Это несовместимое обновление с v0, которое ещё не прошло достаточную проверку в реальном использовании; перед большой синхронизацией протестируйте ограниченную загрузку. Для существующей установки начните с [перехода на v1](migration-v1.md).

Kemono больше недоступен, и Pawchive является единственным поддерживаемым сервером. Исходный файл OpenAPI Pawchive остаётся неизменным, чтобы сравнивать изменения созданного клиента с нормализованным контрактом.

## Поддержка и ресурсы

Перед уходом с сайта документации используйте поиск и [частые вопросы](faq.md). Если ответа нет, используйте внешние ссылки с понятным назначением:

- [трекер проблем](https://github.com/Ljzd-PRO/KToolBox/issues) для воспроизводимых дефектов;
- [Discussions](https://github.com/Ljzd-PRO/KToolBox/discussions) для вопросов и предложений;
- [Releases](https://github.com/Ljzd-PRO/KToolBox/releases) для опубликованных примечаний и файлов;
- [репозиторий исходного кода](https://github.com/Ljzd-PRO/KToolBox) для кода и истории вкладов.

## Качество и лицензия

Стандартный набор тестов работает полностью автономно и блокирует случайный доступ к сети. CI проверяет контракты OpenAPI, детерминированное создание, тесты, Ruff, Mypy, байт-код Python, пакеты, сборку WebUI и строгую сборку MkDocs.
