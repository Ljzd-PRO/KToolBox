# WebUI

WebUI — рекомендуемый способ работы с KToolBox. В одном интерфейсе браузера собраны настройки, задачи, прогресс и история проекта синхронизации.

## Первый запуск

Установите пакет WebUI, создайте каталог проекта и запустите KToolBox:

```bash
pipx install "ktoolbox[webui]"
mkdir ktoolbox-project
cd ktoolbox-project
ktoolbox webui .
```

Браузер откроется автоматически. Войдите с именем `admin` и случайным паролем из терминала. Если `ktoolbox.toml` отсутствует, KToolBox создаст его; новые задачи по умолчанию используют каталог проекта `downloads`.

![Обзор KToolBox WebUI](../assets/webui/40-overview-showcase-desktop-light.png)

## Первая синхронизация

1. Откройте **Авторы** и выберите **Добавить автора**.
2. Вставьте URL автора Pawchive либо укажите платформу и ID.
3. Откройте **Задачи**, выберите **Создать задачу**, затем **Синхронизировать авторов**.
4. Пока проверяете нового автора и формат имён, ограничьте число работ.
5. Откройте задачу, чтобы следить за загрузками, скоростью, повторами и полезными сообщениями.

Завершённые файлы сохраняются, совместимые временные файлы можно продолжить, а ошибка одного автора не удаляет успешные загрузки той же задачи.

## Необязательная постоянная учётная запись

Для первого запуска достаточно созданных данных. Чтобы сохранить тот же вход после перезапуска, создайте хеш пароля:

```bash
ktoolbox webui hash-password
```

Добавьте результат в `.env` проекта:

```dotenv
KTOOLBOX_WEBUI__USERNAME=owner
KTOOLBOX_WEBUI__PASSWORD_HASH='$argon2id$v=19$...'
```

## Безопасный доступ

Встроенный сервер использует HTTP. Для работы на одном компьютере привяжите его к `127.0.0.1`:

```bash
ktoolbox webui . --host 127.0.0.1
```

Для удалённого доступа используйте доверенную сеть или обратный прокси HTTPS. Любой вошедший пользователь видит пути, настройки и журналы проекта, поэтому не давайте доступ недоверенным людям. Один проект может одновременно обслуживать только один процесс WebUI.
