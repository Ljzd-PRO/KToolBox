# Добро пожаловать в KToolBox

KToolBox загружает общедоступные работы из Pawchive. Рекомендуется использовать WebUI: обычные действия представлены понятными формами, а ход выполнения остаётся видимым после перехода на другую страницу.

!!! warning "Новая основная версия"
    v1 ещё недостаточно проверена в реальных условиях, поэтому некоторые функции могут работать с ошибками. Перед переносом сохраните резервные копии настроек и загрузок и сообщайте о неожиданном поведении.

## Начните с WebUI

1. Установите пакет WebUI.
2. Создайте каталог проекта синхронизации.
3. Запустите KToolBox в этом каталоге.

```bash
pipx install "ktoolbox[webui]"
mkdir ktoolbox-project
cd ktoolbox-project
ktoolbox webui .
```

Браузер откроется автоматически. Войдите с именем `admin` и случайным паролем из терминала, добавьте автора и создайте первую задачу. При необходимости KToolBox создаст `ktoolbox.toml`; каталог вывода по умолчанию — `downloads`.

## Безопасные значения по умолчанию

WebUI создаёт данные входа, отключает просмотр чувствительных медиа и использует каталог вывода внутри проекта. Для доступа только с этого компьютера привяжите сервер к `127.0.0.1`; в недоверенной сети используйте HTTPS. KToolBox не реализует учётные записи и избранное Pawchive.
