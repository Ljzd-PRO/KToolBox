# MCP

KToolBox запускает сервер MCP Streamable HTTP в одном процессе и на одном порту с WebUI. Он предоставляет отобранные инструменты для проекта, задач, авторов, правил исключения, поиска Pawchive, формата имён, автоматической синхронизации и безопасной конфигурации. Сеансы браузера и клиенты MCP используют разные учётные данные.

| Сервис | Адрес по умолчанию |
| --- | --- |
| WebUI | `http://127.0.0.1:8789/` |
| MCP | `http://127.0.0.1:8789/mcp` |
| WebUI REST OpenAPI | `http://127.0.0.1:8789/api/v1/openapi.yaml` |

Для скачивания OpenAPI требуется авторизованный сеанс WebUI. Канонический контракт в репозитории — `webui/openapi.yaml`.

## Создание токена доступа

1. Запустите WebUI и войдите.
2. Откройте **MCP** на боковой панели.
3. Выберите создание токена доступа.
4. Укажите понятное имя и подтвердите текущий пароль WebUI.
5. Выберите права только на чтение или управление, затем срок 7, 30, 90, 365 дней либо без срока.
6. Сразу сохраните показанное значение `ktmcp_...`: открытый токен отображается только один раз.

KToolBox хранит только хеш токена. Страница MCP показывает время создания, истечения и последнего использования и позволяет немедленно отозвать токен. Бессрочный токен действует до отзыва и подходит только при активном управлении его жизненным циклом.

## Подключение Codex

Храните токен вне репозитория:

```shell
export KTOOLBOX_MCP_TOKEN="ktmcp_..."
```

Добавьте сервер в конфигурацию Codex:

```toml
[mcp_servers.ktoolbox]
url = "http://127.0.0.1:8789/mcp"
bearer_token_env_var = "KTOOLBOX_MCP_TOKEN"
```

Страница MCP также создаёт конфигурации для обычных HTTP-клиентов, Claude, Cursor, VS Code и Codex. Шаблоны используют переменную окружения или защищённый ввод, а не встраивают токен.

## Права и ограничения

- Токен только для чтения позволяет просматривать сводку проекта, задачи, авторов, правила исключения, автоматическую синхронизацию, историю форматов, очищенную конфигурацию и ограниченный список файлов проекта.
- Токен управления также выполняет явно перечисленные изменения задач, авторов, правил, автоматической синхронизации и безопасной структурированной конфигурации.
- Вход, выход, сеансы браузера, исходное редактирование dotenv/TOML, секреты, произвольный доступ к файловой системе хоста, удаление вывода и неограниченные журналы или содержимое не предоставляются.
- Поиск и запросы Pawchive являются открытыми операциями и могут обращаться к настроенному сервису.
- Списки, журналы, события, тексты произведений и файлы ограничены или разбиты на страницы.

Фактический набор инструментов работающей версии показывает страница **MCP**.

## Безопасность

Bearer-токен предоставляет прямой доступ к проекту. Не сохраняйте его в Git, истории оболочки, снимках экрана, журналах или сообщениях. Используйте отдельный токен для каждого клиента и отзывайте ненужные данные.

Встроенный сервер использует HTTP. Для клиента на том же компьютере привяжите WebUI к `127.0.0.1`. Для удалённого доступа завершайте HTTPS на доверенном обратном прокси и ограничивайте сетевой доступ.

## Границы API

- Pawchive OpenAPI описывает вышестоящий публичный сервис.
- [Python API](api.md) предоставляет типизированный `PawchiveClient`.
- `webui/openapi.yaml` описывает аутентифицированный REST API WebUI KToolBox.
- `/mcp` предоставляет отобранные MCP-инструменты из контракта WebUI.

REST-контракт WebUI и MCP не заменяют API Pawchive.
