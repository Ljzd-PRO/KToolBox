    MCP¶

    KToolBox は WebUI と同じプロセス、同じポートで Streamable HTTP MCP サーバーを起動します。プロジェクト、タスク、クリエイター、除外ルール、Pawchive 検索、命名形式、自動同期、安全な設定操作から選定したツールを公開します。ブラウザーセッションと MCP クライアントの認証情報は別です。

    サービス 既定のアドレス
    WebUI http://127.0.0.1:8789/
    MCP http://127.0.0.1:8789/mcp
    WebUI REST OpenAPI http://127.0.0.1:8789/api/v1/openapi.yaml

    OpenAPI のダウンロードには、認証済みの WebUI セッションが必要です。リポジトリ内の正式な契約は webui/openapi.yaml です。

    アクセストークンを作成¶

    1. WebUI を起動してログインします。
    2. サイドバーの MCP を開きます。
    3. 「アクセストークンを作成」を選びます。
    4. 識別しやすい名前を入力し、現在の WebUI パスワードを再入力します。
    5. 読み取り専用または管理権限と、7、30、90、365 日または無期限を選びます。
    6. 表示された ktmcp_... をすぐに保存します。平文の表示は一度だけです。

    KToolBox が保存するのはトークンのハッシュだけです。MCP ページでは作成、期限、最終使用日時を確認し、即座に失効できます。無期限トークンは失効するまで有効なため、ライフサイクルを管理できる場合にのみ使用してください。

    Codex に接続¶

    トークンをリポジトリ外の環境変数に保存します。

    export KTOOLBOX_MCP_TOKEN="ktmcp_..."

    Codex 設定に追加します。

    [mcp_servers.ktoolbox]
url = "http://127.0.0.1:8789/mcp"
bearer_token_env_var = "KTOOLBOX_MCP_TOKEN"

    MCP ページでは、汎用 HTTP、Claude、Cursor、VS Code、Codex 向け設定も生成できます。テンプレートはトークンを埋め込まず、環境変数または保護入力を使用します。

    権限と制限¶

    • 読み取り専用トークンは、プロジェクト概要、タスク、クリエイター、除外ルール、自動同期、命名履歴、秘匿化済み設定、上限付きプロジェクトファイルを参照できます。
    • 管理トークンは、ツール一覧に明記されたタスク、クリエイター、除外ルール、自動同期、安全な構造化設定も変更できます。
    • ログイン、ログアウト、ブラウザーセッション、dotenv/TOML 原文編集、秘密値、任意のホストファイルシステム、出力削除、無制限ログや本文は公開しません。
    • 検索と Pawchive 参照は、設定済み Pawchive サービスへ接続するオープンワールド操作です。
    • ツール一覧、ログ、イベント、作品本文、ファイルには上限またはページングがあります。

    実行中のバージョンで利用できるツールは MCP ページの一覧が正です。

    セキュリティ¶

    Bearer トークンはプロジェクトへ直接アクセスできます。Git、シェル履歴、スクリーンショット、ログ、チャットへ保存しないでください。クライアントごとに別のトークンを使い、不要な認証情報を失効してください。

    内蔵サーバーは HTTP を使用します。同じコンピューター上のクライアントでは WebUI を 127.0.0.1 にバインドしてください。リモートアクセスでは、信頼できるリバースプロキシで HTTPS を終端し、ネットワークアクセスを制限します。

    API の区別¶

    • Pawchive OpenAPI は上流の公開サービスを記述します。
    • Python API は型付き PawchiveClient を提供します。
    • webui/openapi.yaml は認証付き KToolBox WebUI REST API を記述します。
    • /mcp は WebUI 契約から選定した MCP ツールを公開します。

    WebUI REST 契約と MCP は Pawchive API の代替ではありません。
